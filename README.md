# Krush ESP for ROB RUN (free build)

Download: soon

Visual-only cut of the Krush build: role colors, boxes, cash trail.

## Layers

| Layer | Default | Range |
| --- | --- | --- |
| player boxes | on | 500 |
| skeleton | on | 500 |
| role labels | on | 500 |
| cash markers | on | 350 |
| camera markers | off | 250 |

## Role colors

Police blue, criminals red, neutrals grey. Swap two presets if the default clashes with your HUD.

## Install

Admin loader, ROB RUN, INSERT, F2 toggles.

## Troubleshooting

Colors flat: role table stale after patch. Markers missing: layer off or range too low.

Windows 10/11, Steam, EAC. Free build.
